long-lived-connections

Minimal test frontend — connects to client-api over SSE and Socket.IO, and can trigger messages via worker. Used to see graceful shutdown working: kill/rolling-restart a client-api instance and watch this page reconnect on its own. See the README.

Config

Defaults match the docker compose port mappings and the kubectl port-forward commands in the README — leave them as-is unless you've mapped different local ports.
